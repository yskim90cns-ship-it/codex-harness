# PRD: Live Voice Translator

## 목표
마이크로 입력된 음성을 실시간으로 인식하고, 선택한 대상 언어로 번역한 결과를 지연이 적은 자막 형태로 보여주는 웹사이트를 만든다.

## 사용자
- 외국어 회의, 강의, 인터뷰를 실시간으로 이해해야 하는 개인 사용자
- 짧은 대면 대화나 온라인 통화 내용을 빠르게 번역해 보고 싶은 사용자
- 별도 앱 설치 없이 브라우저에서 바로 음성 번역을 사용하려는 사용자

## 핵심 기능
1. 마이크 권한 요청 및 실시간 음성 입력 시작/중지
2. 입력 언어와 출력 언어 선택
3. 실시간 원문 전사 표시
4. 실시간 번역 결과 표시
5. 부분 인식 결과와 확정 인식 결과를 구분해서 보여주기
6. 세션 중 발생한 오류, 권한 거부, 네트워크 실패 상태 표시
7. 최근 번역 문장 히스토리 표시

## 핵심 사용자 흐름
1. 사용자가 사이트에 접속한다.
2. 입력 언어와 번역 대상 언어를 선택한다.
3. 사용자가 마이크 시작 버튼을 누른다.
4. 브라우저가 마이크 권한을 요청한다.
5. 사용자가 말하면 원문 전사가 먼저 표시된다.
6. 전사된 문장이 안정화되면 번역 API를 통해 대상 언어 번역을 가져온다.
7. 사용자는 화면에서 원문과 번역 자막을 동시에 확인한다.
8. 사용자가 중지 버튼을 누르면 세션이 종료되고 히스토리가 유지된다.

## MVP 범위
- 단일 사용자 브라우저 세션만 지원한다.
- 텍스트 번역 결과만 제공한다.
- 한국어, 영어, 일본어, 중국어, 스페인어를 우선 지원한다.
- 브라우저 내 음성 인식 또는 서버 API 연동 중 하나의 안정적인 경로를 선택해 구현한다.
- 외부 번역 API 키는 서버 환경 변수에서만 읽는다.

## MVP 제외 사항
- 사용자 계정, 로그인, 결제
- 번역 세션 저장 및 클라우드 동기화
- 음성 합성으로 번역 결과를 읽어주는 기능
- 다자간 회의방, 실시간 공유 링크
- 모바일 네이티브 앱
- 녹음 파일 업로드 번역
- 전문 통역 품질을 보장하는 도메인별 용어집

## 성공 기준
- 사용자가 3초 이내에 마이크 입력을 시작할 수 있다.
- 일반적인 짧은 문장은 말한 뒤 2초 이내에 번역 결과가 화면에 표시된다.
- 마이크 권한 거부, 네트워크 오류, 번역 API 오류가 사용자에게 명확히 표시된다.
- API 키나 외부 서비스 인증 정보가 클라이언트 번들에 포함되지 않는다.
- 주요 기능은 테스트를 먼저 작성한 뒤 구현한다.

## 디자인
- 매일 쓰는 실시간 도구처럼 보여야 한다. 마케팅 랜딩 페이지가 아니라 작업 화면을 첫 화면으로 둔다.
- 다크 모드 고정, 고대비 텍스트, 자막 가독성을 우선한다.
- 색상은 중립 배경에 녹색 계열 상태 색상과 청록색 액센트만 제한적으로 사용한다.
